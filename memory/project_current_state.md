# BeehiveScale ESP32 — текущее состояние

**Версия:** v5.0.24 (2026-05-17)
**Статус:** работает на макетной сборке, корпус собран, тестируется wake-up из deep sleep
**Главный блокер:** ждём детали (1N5819, AO3401, Type-C female) для солнечной зарядки и P-MOSFET LCD

**Why:** проект для пасеки Геннадия — автономные весы которые шлют отчёты в Telegram. Тяжело пробираться через каждое железное решение — каждое прошитие через USB, не разбирая корпуса.

**How to apply:** при заходе в проект сразу читай это + project_session_2026-05-17.md чтобы понять что было сделано последнее. Не предлагай разборку корпуса — Геннадий устал. Прошивки только через USB-C.

## Железо у Геннадия (собрано в корпусе)

| Компонент | Что |
|---|---|
| MCU | ESP32-WROOM-32 DevKit V1 |
| LDO | **HT7333** (заменён AMS1117, -5 мА в sleep) |
| Boost | **MT3608** настроен на 5.0В (заменил сгоревший AS21) |
| Банка | 21700 4500 мА·ч |
| Зарядка | TP4056 + DW01 |
| Делитель | R1+R2 100k → GPIO34 (откалиброван через сайт, ratio ~2.124) |
| HX711 | + pull-up 10к на SCK (D17) → 3V3 (обязательно для sleep!) |
| LCD | 1602 I²C PCF8574 (адрес 0x27) |
| RTC | DS3231 на **3V3** (не 5В!) |
| Темп | DS18B20 + 4.7к pullup |
| Кнопки | MAIN (D27, RTC GPIO) + MENU (D26) |
| LED | **все выпаяны** (ESP32 ×2 + DS3231 ×2 + TP4056 ×2) |

## Замеры на железе

- Active: ~120 мА
- Deep sleep: **6 мА**

## Solar panel параметры

TZT solar panel 5В / 200мА / 1Вт (107×61мм). Подключение по схеме:
```
Panel → провод → Type-C male
              → Type-C female на корпусе
              → 1N5819 (полоска к TP4056)
              → 470µF параллельно
              → TP4056 VIN (через VBUS pin Type-C)
```

Расчёт: летом ~750-900 мА·ч/день в банку, при расходе 200 мА·ч/день → прибыль ~600 мА·ч/день. В улей с панелью — поставить и забыть на сезон.
