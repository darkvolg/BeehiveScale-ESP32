# /compact — обязательное сохранение состояния

**Rule:** перед сжатием контекста через /compact в проекте BeehiveScale-ESP32 нужно сохранить:
1. Список изменённых файлов в сессии с кратким описанием
2. Использованные команды сборки/прошивки/тестирования
3. Текущий план — что сделано, что осталось

**Why:** правило указано в проектном CLAUDE.md явным образом — "При выполнении /compact перед сжатием контекста обязательно сохрани в память". Это пункт собственника проекта.

**How to apply:**
- Сохранять в `memory/MEMORY.md` или отдельный файл `memory/project_compact_YYYY-MM-DD.md`
- Дополнительно сделать `lightrag_insert` со сжатой сводкой сессии
- Команды (pio run, git push) — записывать дословно для будущей сессии
- Текущий план — In-progress и pending TodoWrite задачи
