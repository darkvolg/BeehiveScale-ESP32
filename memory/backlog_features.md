# Backlog — что обсуждали, не сделали

**Why:** в сессии 2026-05-11 обсуждалось много вариантов, в код пошёл минимальный набор. Чтобы не забыть остальное.
**How to apply:** перед предложением "давай добавим" — проверь, есть ли уже в этом списке. Не плоди дубли.

## 🟡 P2 — Полезно, рассмотреть в будущем

### График в Архивной вкладке
Сейчас график только на отдельной /chart (за день). В архиве — только лента карточек. Геннадий обмолвился что главное это лента, но общий график за период тоже был бы полезен. Решение: один большой график вверху архивной секции, Chart.js уже подгружен в PAGE_HTML, добавить ~30 строк JS.

### Кнопка "Отправить лог в Telegram документом"
При наличии Wi-Fi на пасеке ESP32 шлёт CSV через Telegram sendDocument. Польза: лог в облаке Telegram, доступен с ПК потом. Условно полезно — Геннадий и так может скачать на телефон. Решение: добавить если запросит, не приоритет.

### Anomaly threshold отдельно для архива
Сейчас порог 🔴 в архиве = alert_delta (тот же что для Telegram-алертов). Геннадий не запрашивал отдельный — пока правильно. Если будет жаловаться что "в архиве краснит слишком много / мало" — добавить отдельную настройку.

## 🟢 P3 — Только если железо/инфраструктура изменится

### HTTPS для полноценной PWA на iOS
Самоподписанный сертификат на ESP32. При первом заходе iPhone предупреждение. После доверия — работает. Push-уведомления через SW требуют HTTPS. Условно полезно. Решение: только если Геннадий перейдёт с Android (если он на Android — не делаем).

### GSM-модуль SIM800L / SIM7600
Обсуждали как альтернативу Wi-Fi для удалённого мониторинга. Минусы: SIM800L пик 2А, нужен буферный конденсатор, 2G сворачивают в РФ, оперрасходы на тариф. Решение: Геннадий подумает. Не делаем пока сам не попросит и не купит модуль.

### Раздача интернета с телефона на пасеке
Геннадий упоминал что может раздавать с телефона. Это уже работает с текущим WiFi STA mode. Никаких изменений в коде не нужно — настраивается через /wifi.

## ⚪ P4 — Архитектурные / далёкие

### Native mobile app
Месяцы работы, $99/год Apple, дублирование. Закрыто — PWA покрывает 90% нужд. Не возвращаться к этому без сильного бизнес-обоснования.

### Облако / multi-hive
Один пчеловод → один улей. Если будет масштабирование на много ульев одного пчеловода — нужен центральный сервер. Не в этом проекте.
