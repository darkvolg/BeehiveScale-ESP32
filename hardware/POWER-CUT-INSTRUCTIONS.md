# BeehiveScale — Power-Cut модуль

Инструкция по сборке и установке. Делается на маленькой DIY-плате (~2.5×3 см) и встаёт в разрыв питания между TP4056 и MT3608.

---

## 1. ДЕТАЛИ

| # | Деталь | Кол-во |
|---|---|---|
| 1 | AO3401 P-MOSFET (SOT-23) | 1 |
| 2 | 1N5819 Шоттки диод | 2 |
| 3 | Резистор 100kΩ | 1 |
| 4 | Кнопка тактовая (push-button) | 1 (SW2 WAKE) |
| 5 | Тумблер ON/OFF | 1 (SW1 main — внешний на корпусе) |
| 6 | Перфоборд ~2.5×3 см | 1 |
| 7 | Тонкий провод (МГТФ или подобный) | ~50 см |

---

## 2. РАСПИНОВКА

### AO3401 (маркировка A19T, корпус SOT-23)
Вид сверху, маркировка читается:
- **Pin 3 (Drain)** — ОДИНОЧНАЯ ножка СВЕРХУ
- **Pin 1 (Gate)** — НИЖНЯЯ ЛЕВАЯ
- **Pin 2 (Source)** — НИЖНЯЯ ПРАВАЯ

```
       Pin 3 (D)
          │
       ┌──┴──┐
       │A19T │
       └─┬─┬─┘
         │ │
       Pin1 Pin2
        G    S
```

### 1N5819 (диод)
- **Анод** = без полоски
- **Катод** = с полоской

```
Анод ─►├─ Катод (полоска)
```

### Тактовая кнопка (SW2)
Любые 2 контакта замыкаются при нажатии.

---

## 3. NETLIST ПЛАТЫ (все соединения)

Точки на плате:
- **G** = AO3401 Gate (Pin 1, низ-лево)
- **S** = AO3401 Source (Pin 2, низ-право)
- **D** = AO3401 Drain (Pin 3, верх)
- **GND** = общая земля
- **K_D1** = катод D1 (для CTRL_RTC)
- **K_D2** = катод D2 (для CTRL_ESP)

| Соединение | Что соединяет |
|---|---|
| N1 | AO3401 G ↔ резистор 100k один вывод |
| N2 | AO3401 S ↔ резистор 100k другой вывод |
| N3 | AO3401 G ↔ диод D1 анод |
| N4 | AO3401 G ↔ диод D2 анод |
| N5 | AO3401 G ↔ кнопка SW2 один контакт |
| N6 | SW2 другой контакт ↔ GND |
| N7 | D1 катод ↔ выходная площадка CTRL_RTC |
| N8 | D2 катод ↔ выходная площадка CTRL_ESP |

В общую точку **AO3401 Gate** сходятся: резистор, D1 анод, D2 анод, SW2 контакт. **5 проводников в одной точке.**

В общую точку **AO3401 Source** сходятся: резистор другой вывод, выходные провода VBAT_IN и VCC_RTC.

---

## 4. ВЫХОДНЫЕ ПРОВОДА (6 шт. идут с платы наружу)

| Провод | Откуда на плате | Куда подключать |
|---|---|---|
| **VBAT_IN** | AO3401 S (Source) | → SW1 → TP4056 OUT+ |
| **VBAT_OUT** | AO3401 D (Drain) | → MT3608 VIN+ |
| **VCC_RTC** | AO3401 S (Source, та же точка что VBAT_IN) | → DS3231 VCC |
| **GND** | площадка GND на плате | → общая земля (TP4056 OUT−, MT3608 GND) |
| **CTRL_RTC** | катод D1 | → DS3231 INT/SQW pin |
| **CTRL_ESP** | катод D2 | → ESP32 GPIO25 |

---

## 5. ПОШАГОВАЯ ПАЙКА ПЛАТЫ

### Шаг 1: AO3401 на перфоборд
1. Положи AO3401 маркировкой A19T вверх
2. Ориентируй Pin 3 (Drain) к ВЕРХу платы, Pin 1 (Gate) к НИЖ-ЛЕВОму углу, Pin 2 (Source) к НИЖ-ПРАВОму
3. Зафиксируй пинцетом, припаяй 3 ножки
4. **Проверка multimeter continuity**: G↔S, G↔D, S↔D — все ∞ (нет короткого)

### Шаг 2: Резистор 100k (pullup)
1. Один вывод резистора → припаять к точке **AO3401 Gate**
2. Другой вывод → припаять к точке **AO3401 Source**
3. **Проверка**: Ом между G и S = **~100kΩ**

### Шаг 3: Диод D1 (1N5819)
1. Анод (без полоски) → припаять к точке **AO3401 Gate** (там же где резистор)
2. Катод (с полоской) → припаять к свободной краевой площадке → это **CTRL_RTC**
3. **Проверка диод-режим**: красный щуп на анод, чёрный на катод → ~0.2V. Обратно → ∞.

### Шаг 4: Диод D2 (1N5819)
1. Анод → к **AO3401 Gate** (общая точка с резистором и D1 анодом)
2. Катод → к другой краевой площадке → это **CTRL_ESP**
3. **Проверка**: аналогично D1

### Шаг 5: Кнопка SW2 (WAKE)
1. Один контакт кнопки → к **AO3401 Gate** (общая точка)
2. Другой контакт → к площадке **GND** (отдельной, можно тоже на краю платы)
3. **Проверка continuity**:
   - Не нажата: G ↔ GND = ∞
   - Нажата: G ↔ GND = 0 (звук в multimeter)

### Шаг 6: Припаять 6 проводов наружу
Каждый длиной ~10-15 см. Можно цветным маркером пометить.

| Провод | Цвет (предложение) | От точки на плате |
|---|---|---|
| VBAT_IN | красный | AO3401 Source |
| VBAT_OUT | красный | AO3401 Drain |
| VCC_RTC | оранжевый/розовый | AO3401 Source (та же точка) |
| GND | чёрный | площадка GND |
| CTRL_RTC | зелёный | катод D1 |
| CTRL_ESP | синий | катод D2 |

## 6. ПРОВЕРКА ПЛАТЫ ДО УСТАНОВКИ

Multimeter тесты:

### Тест A — нет коротких замыканий
- VBAT_IN ↔ GND = **∞**
- VBAT_OUT ↔ GND = **∞**
- VBAT_IN ↔ VBAT_OUT = **∞** (MOSFET закрыт)
- CTRL_RTC ↔ CTRL_ESP = **∞** (диоды разделены)
- CTRL_RTC ↔ GND = **∞**

### Тест B — pullup работает
- VBAT_IN ↔ CTRL_RTC = ~100kΩ (через резистор + анод D1)

### Тест C — MOSFET переключается
- Multimeter Ом между VBAT_IN и VBAT_OUT = **∞** (закрыт)
- Соединить проводком CTRL_RTC ↔ GND (имитация alarm)
- Снова Ом VBAT_IN ↔ VBAT_OUT = **близко к 0** (открылся!)
- Снять перемычку → опять **∞**

### Тест D — кнопка WAKE работает
- Ом VBAT_IN ↔ VBAT_OUT = ∞
- **Нажать SW2** → VBAT_IN ↔ VBAT_OUT = **близко к 0**
- Отпустить → ∞

**ВСЕ 4 теста должны пройти. Иначе НЕ ставь на боевое железо — перепаяй.**

## 7. УСТАНОВКА В СУЩЕСТВУЮЩЕЕ ЖЕЛЕЗО

### Шаг 7.1 — Выключить всё
1. USB отключить от ESP
2. Тумблер 21700 в OFF (или вынь банку)
3. Multimeter подтверди VBAT = 0 на TP4056 OUT+

### Шаг 7.2 — Найти провод TP4056 OUT+ → MT3608 VIN+
Сейчас они напрямую соединены коротким проводом. Найди этот провод, **перережь посередине**, зачисти концы, олудь.

### Шаг 7.3 — Установить SW1 (главный тумблер) если ещё нет
Если у тебя уже есть тумблер на корпусе на пути от банки — пропусти.

Иначе подключи SW1 в разрыв:
- Один контакт SW1 ↔ TP4056 OUT+
- Другой контакт SW1 ↔ VBAT_IN платы

### Шаг 7.4 — Подключить плату
- **VBAT_IN** (плата) ↔ (через SW1) ↔ TP4056 OUT+
- **VBAT_OUT** (плата) ↔ MT3608 VIN+
- **GND** (плата) ↔ к любой точке GND (TP4056 OUT−, MT3608 GND, общая шина)

### Шаг 7.5 — Переподключить DS3231 VCC
Сейчас DS3231 VCC скорее всего идёт от ESP 3V3 pin.

1. Отпаять провод DS3231 VCC от ESP 3V3
2. Припаять этот провод к **VCC_RTC** платы
3. Теперь DS3231 получает питание от TP4056 OUT через AO3401 Source — всегда живёт пока SW1 ON

### Шаг 7.6 — Подключить управление
- **CTRL_RTC** (плата) ↔ DS3231 **INT/SQW** pin
- **CTRL_ESP** (плата) ↔ ESP32 **GPIO25** pin

### Шаг 7.7 — Проверить ничего больше не трогали
- MT3608 → ESP VIN, LCD, HX711, DS18B20 — **БЕЗ ИЗМЕНЕНИЙ**
- TP4056 IN+/IN-, B+/B- — **БЕЗ ИЗМЕНЕНИЙ**

## 8. ПЕРВЫЙ ЗАПУСК

### 8.1 — Включить
1. Тумблер 21700 ON
2. SW1 ON
3. **Ничего не происходит** — это нормально (AO3401 закрыт по умолчанию)
4. LCD не горит, ESP без питания

### 8.2 — Триггер WAKE кнопкой
1. **Нажать SW2** (WAKE) на ~0.5 секунды
2. ESP должен загрузиться:
   - LCD загорается (splash screen)
   - В Serial Monitor: `[BeehiveScale v5.0.30] boot`
   - WiFi подключение
3. **Отпустить SW2** — ESP сам держится через GPIO25 HOLD

### 8.3 — Автоматический цикл
После прошивки v5.0.30 ESP:
1. Запрограммирует DS3231 alarm на +5 минут (или по расписанию)
2. Сделает работу (WiFi, TG, измерения)
3. Освободит GPIO25 → MOSFET закроется → ESP выключится
4. Через 5 минут → DS3231 alarm → INT LOW → MOSFET ON → ESP boot

---

## 9. ПОВЕДЕНИЕ ВЫКЛЮЧАТЕЛЕЙ

### SW1 (главный тумблер ON/OFF)
| Состояние | Что происходит |
|---|---|
| **ON** | Устройство работает. AO3401 управляет ESP. DS3231 запитан. |
| **OFF** | Всё обесточено. DS3231 на CR2032 backup (только время). ESP off. |

### SW2 (кнопка WAKE)
| Действие | Результат |
|---|---|
| Нажать | Gate→GND, MOSFET ON, ESP boot |
| Отпустить | ESP уже держит HOLD через GPIO25, продолжает работать |

### DS3231 alarm
| Событие | Результат |
|---|---|
| Время match alarm | INT pin → LOW → через D1 → Gate LOW → MOSFET ON → ESP boot |
| ESP очистил alarm flag | INT → HIGH, но ESP держит HOLD |

## 10. ЕСЛИ ЧТО-ТО НЕ ТАК

| Симптом | Причина | Решение |
|---|---|---|
| Нажимаю SW2 — ESP не включается | MOSFET не открывается | Проверь полярность D1/D2, ориентацию AO3401, провод GPIO25→CTRL_ESP |
| ESP включается на 1 сек и выключается | HOLD не работает | Проверь D2 анод→Gate, катод→GPIO25. Проверь код: setup() должен сделать GPIO25=OUTPUT, digitalWrite(25,LOW) |
| LCD не горит, но Serial есть | Проблема LCD (не связано с power-cut) | Проверь LCD питание 5V |
| Banка садится за день | Утечка тока | SW1 OFF, multimeter mA в разрыв 21700+ → должно быть <0.5 мА |
| DS3231 теряет время после выключения SW1 | CR2032 села или не вставлена | Замени CR2032, проверь контакт |

## 11. ИТОГОВЫЙ ЧЕК-ЛИСТ

После всех шагов:
- [ ] Плата собрана и проверена multimeter (4 теста)
- [ ] Плата установлена в разрыв TP4056 OUT+ → MT3608 VIN+
- [ ] SW1 установлен (внешний тумблер)
- [ ] DS3231 VCC переподключён к VCC_RTC платы
- [ ] CTRL_RTC подключён к DS3231 INT
- [ ] CTRL_ESP подключён к ESP GPIO25
- [ ] SW1 OFF → multimeter mA → <100 µA
- [ ] SW1 ON, SW2 не нажата → multimeter mA → <200 µA
- [ ] SW2 нажата → ESP boot за <1 сек
- [ ] DS3231 alarm через 5 мин → ESP сам boot (после прошивки v5.0.30)

**Когда все галочки ✅ — железо готово, прошить v5.0.30.**
