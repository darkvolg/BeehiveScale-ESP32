BeehiveScale — Power-Cut модуль (v5.0.30)

Цель: ESP32 физически выключается между циклами через P-MOSFET AO3401. DS3231 alarm включает питание. ESP сам себя выключает после работы. 100% надёжность — нет багов deep sleep WiFi.

2. Распиновка AO3401 (A19T)

Смотри сверху на маркировку A19T:

Pin 3 (D — Drain) │ ┌──┴──┐ │ │ │A19T │ │ │ └─┬─┬─┘ │ │ Pin1 Pin2 G S (Gate)(Source)
  • Pin 3 = D (Drain) — одиночная ножка СВЕРХУ
  • Pin 1 = G (Gate) — нижняя ЛЕВАЯ
  • Pin 2 = S (Source) — нижняя ПРАВАЯ

3. Распиновка 1N5819 (диод)

Анод Катод ─────►├───── ↑ белая полоска

Полоска на корпусе диода = катод. Анод — противоположный конец без полоски.

6. Пошаговая пайка платы

1Установка AO3401

Положи AO3401 маркировкой A19T вверх. Ориентируй так чтобы Pin 3 (Drain) смотрел вверх, Pin 1 (Gate) — нижняя левая, Pin 2 (Source) — нижняя правая. Зафиксируй пинцетом, припаяй 3 ножки.

Проверка: multimeter continuity между всеми тремя пинами = ∞ (нет коротких).

2Резистор 100k (pullup)

Один вывод резистора → AO3401 Pin 1 (Gate). Другой → AO3401 Pin 2 (Source).

Проверка: Ом между G и S = ~100kΩ.

3Диод D1 (от DS3231)

Анод (без полоски) → AO3401 Gate (там же где резистор).
Катод (с полоской) → краевая площадка → провод CTRL_RTC.

Проверка: диод-режим. Красный щуп на анод, чёрный на катод → ~0.2V. Обратно → ∞.

4Диод D2 (от ESP)

Анод → AO3401 Gate (та же общая точка).
Катод → другая краевая площадка → провод CTRL_ESP.

5Кнопка SW2 (WAKE)

Один контакт кнопки → AO3401 Gate (общая точка).
Другой контакт → площадка GND на плате.

Проверка continuity: кнопка не нажата → G↔GND = ∞. Нажата → 0Ω (звук).

66 проводов наружу

Припаяй провода по таблице из раздела 5. Длина каждого ~10–15 см.

8. Установка в существующее железо

ВНИМАНИЕ: ESP32 GPIO33 — где раньше был подключён DS3231 INT — теперь НЕ ИСПОЛЬЗУЕТСЯ. Этот провод нужно отпаять от ESP (уже сделано). На будущее можно оставить пятак или использовать GPIO33 для чего-то другого.
1Выключить всё
  • USB отключить от ESP
  • Тумблер 21700 в OFF (или вынь банку)
  • Multimeter подтверди что VBAT = 0 на TP4056 OUT+
2Перерезать провод TP4056 OUT+ → MT3608 VIN+

Найди провод между TP4056 OUT+ и MT3608 VIN+. Перережь посередине, зачисти концы, олудь.

3Установить SW1 (главный тумблер)

Если уже есть на корпусе — пропусти. Иначе подключи SW1 в разрыв:

  • Один контакт SW1 → TP4056 OUT+ (конец провода)
  • Другой контакт SW1 → VBAT_IN платы
4Подключить плату к существующему железу
  • VBAT_IN → (через SW1) → TP4056 OUT+
  • VBAT_OUT → MT3608 VIN+
  • GND → общая земля (любая точка GND)
5DS3231 VCC переподключить

Сейчас DS3231 VCC скорее всего идёт от ESP 3V3. Отпаять его оттуда. Припаять к проводу VCC_RTC платы.

Теперь DS3231 получает питание от TP4056 OUT (через AO3401 Source) — всегда живёт когда SW1 ON.

6Подключить управление
  • CTRL_RTC → DS3231 INT/SQW pin
  • CTRL_ESP → ESP32 GPIO25 pin

Заметка: ESP32 GPIO33 (где раньше был INT) — теперь свободен, можно оставить.

7Что НЕ трогать
  • MT3608 → ESP VIN, LCD, HX711, DS18B20 — без изменений
  • TP4056 IN+/IN-, B+/B- — без изменений
  • 21700 банка — без изменений

9. Первый запуск

1Включить
  • Тумблер 21700 → ON
  • SW1 → ON
  • Ничего не происходит — это нормально (AO3401 закрыт по умолчанию)
2Триггер WAKE кнопкой

Нажми SW2 (WAKE) на ~0.5 сек. ESP должен загрузиться:

  • LCD загорается (splash screen)
  • Serial Monitor: [BeehiveScale v5.0.30] boot
  • WiFi подключение

Отпусти SW2 — ESP уже сам держит HOLD через GPIO25.

3Автоматический цикл

После прошивки v5.0.30 ESP:

  1. Запрограммирует DS3231 alarm на +5 мин (или по расписанию)
  2. Сделает работу (WiFi, TG, измерения)
  3. Освободит GPIO25 → MOSFET закроется → ESP выключится
  4. Через 5 мин DS3231 alarm → ESP boot автоматически

12. Финальный чек-лист

  • Плата собрана и проверена multimeter (4 теста)
  • Плата установлена в разрыв TP4056 OUT+ → MT3608 VIN+
  • SW1 установлен (внешний тумблер)
  • DS3231 VCC переподключён к VCC_RTC платы
  • DS3231 INT отпаян от ESP GPIO33 (старый коннект)
  • CTRL_RTC подключён к DS3231 INT/SQW
  • CTRL_ESP подключён к ESP GPIO25
  • SW1 OFF → multimeter mA → <100 µA
  • SW1 ON, SW2 не нажата → mA → <200 µA
  • SW2 нажата → ESP boot за <1 сек
  • DS3231 alarm через 5 мин → ESP сам boot (после прошивки v5.0.30)
Когда все галочки ✅ — железо готово, прошить v5.0.30.
