🔋 Подключение AS21 V6.0 → ESP32

AS21 V6.0 — модуль «всё-в-одном» (TP4056 + DW01 + Boost 5 В + holder 18650). Имеет три точки подключения к ESP32 и один microUSB для зарядки:

Выход AS21 → Куда Назначение
5V_OUT ESP32 VIN (+ LCD VCC) 5 В после Boost — питает ESP32 и LCD
GND ESP32 GND Общая земля для всей схемы
BAT+ (raw) Делитель R1+R2 → ESP32 D34 Прямое напряжение банки (3.0–4.2 В) для ADC батареи
microUSB Зарядное 5 В Только для зарядки — не для прошивки!
💡 Два USB-разъёма на устройстве:
  • microUSB на AS21 — зарядка батареи 18650
  • USB-C на ESP32 DevKit V1 — прошивка и Serial-консоль (115200)
Можно подключать оба одновременно.

⚖️ HX711 — подключение тензодатчика

HX711→ESP32Описание
VCC→3V33.3 В стабильнее, чем 5 В
GND→GNDОбщая земля
DT (DATA)→D16 / GPIO16DT_PIN = 16
SCK (CLK)→D17 / GPIO17SCK_PIN = 17 (сосед с D16, удобно паять шлейфом)
SCK pull-up ⚡ обязательно↑3V3 через резистор 10 кΩУдерживает SCK в HIGH когда ESP32 в deep sleep. Без этого scale.power_down() не работает, HX711 ест +2 мА в sleep
⚡ Критичная аппаратная доработка для автономной работы
В прошивке вызывается scale.power_down() перед deep sleep — HX711 должен уйти в режим 1 мкА.
НО при deep sleep ESP32 пин D17 переходит в Z (D17 — не RTC GPIO, не удерживается).
HX711 видит «провисание» SCK → просыпается → продолжает есть 1.5-2 мА.
Решение: резистор 10 кΩ между D17 и 3V3. Когда GPIO в Z, резистор удерживает SCK в HIGH, HX711 в power-down.
Замер: без pull-up sleep 9 мА · С pull-up sleep 5 мА · Автономия ×2 (14 → 26 дней на 21700).

🕐 DS3231 RTC (адрес 0x68)

DS3231→ESP32Описание
VCC→3V33.3 В — НЕ 5 В (CR2032 не должна заряжаться)
GND→GNDЗемля
SDA→D21 / GPIO21Параллельно LCD на одной шине
SCL→D22 / GPIO22Параллельно LCD на одной шине
SQW (INT) опц.→D33 / GPIO33Alarm output → RTC GPIO ESP32. Задел на P3 — в v5.0.18 не используется (расписание идёт через timer wakeup ESP32). Паяем сейчас чтобы потом не перепаивать
💡 CR2032 — установи батарейку в держатель DS3231, часы не сбросятся при выключении весов. Хватает на 5–10 лет.
⚠️ Power LED и резистор R5 на модуле DS3231: на большинстве модулей DS3231 есть Power LED (~200 мкА) и SMD-резистор R5 в цепи зарядки CR2032. Если используешь не-перезаряжаемую CR2032 — выпаяй оба: иначе батарея проживёт месяцы вместо лет, а LED жжёт ток в deep sleep.

🌡️ DS18B20 — датчик температуры

DS18B20 (плоской стороной)→ESP32Описание
GND (левая ножка)→GNDЗемля
DATA (центральная)→D4 / GPIO41-Wire. TEMP_PIN = 4
VCC (правая ножка)→3V3Питание 3.3 В
DATA + 4.7 кОм → 3V3Pull-up резистор обязателен!
❌ Без резистора датчик не работает! 4.7 кОм между DATA и VCC обязательно. Без него — −127 °C / ошибка.
💡 Длинный кабель в улей — если датчик в гильзе на ~1 м и более, ставь pullup ближе к датчику, не к ESP32.

🔘 Кнопки управления

💡 Внешние резисторы не нужны — используется INPUT_PULLUP, встроенные подтяжки ESP32. Кнопка просто соединяет пин с GND.
КнопкаПин 1Пин 2Функции
MAIN (тара / калибровка) D27 / GPIO27 GND 3 сек = ТАРА (с диалогом MENU=OK)
6 сек = КАЛИБРОВКА. RTC GPIO ⚡ — может разбудить из deep sleep
MENU (навигация / OK) D26 / GPIO26 GND короткое = следующий экран
2.5 сек = OK / на главную
💡 MAIN на RTC GPIO: D27 — это RTC GPIO, поэтому кнопка MAIN способна разбудить ESP32 из deep sleep через esp_sleep_enable_ext0_wakeup().

🔋 Делитель напряжения батареи (D34)

18650 (макс. 4.2 В) делится пополам двумя резисторами 100 кОм. На GPIO34 (ADC1_CH6) попадает ~2.1 В — в пределах диапазона ESP32 ADC с ADC_11db (0–3.3 В).

💡 BAT+ берётся с AS21 — прямое напряжение банки (3.0–4.2 В), а не с выхода 5 В Boost. Ток утечки делителя: 4.2 / 200 кОм ≈ 21 мкА — заметно для deep sleep, но допустимо.
⚠️ GPIO34 — input only! Этот пин ESP32 нельзя выводить как OUTPUT — только чтение. Максимум на нём = 3.3 В, не превышать.

💤 Пробуждение из Deep Sleep (что нового в ESP32)

На ESP8266 v4.1 deep sleep работал плохо: пин D0 был занят HX711, и для пробуждения нужно было ставить перемычку GPIO16 → RST вручную. ESP32 решает это полноценно:

СпособТриггерОписание
Timer wakeup esp_sleep_enable_timer_wakeup() Просыпается через N секунд. Для расписания (например, через 8 часов до 09:00)
EXT0 (DS3231 alarm) опц. D33 → LOW (от SQW) DS3231 alarm подтягивает SQW в LOW → ESP32 просыпается ровно по часам RTC. Задел на P3, в v5.0.18 не реализовано
Кнопка MAIN D27 → LOW RTC GPIO. Можно настроить ext0/ext1 wake для ручного пробуждения
Кнопка RST на плате RST = 0 Полная перезагрузка (теряется RTC RAM, но не EEPROM)
