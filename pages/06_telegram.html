📱 Telegram через Cloudflare Worker

Отчёты по расписанию — через CF Worker-релай. Работает у любого провайдера (Beeline и др.)

📦 Компоненты 🔌 Подключение ⚙️ Настройка ⚙️ Эксплуатация 🌐 Веб-интерфейс 📱 Telegram 🔍 Неисправности

💡 Зачем Cloudflare Worker?

На прошивке v4.1 (ESP8266) ESP отправлял запрос напрямую на api.telegram.org. У провайдера Beeline (и некоторых других в РФ) этот домен заблокирован — отчёты не приходили, в Serial были ошибки CONNECTION_REFUSED.

В v5 ESP32 шлёт запрос на наш Cloudflare Worker (beehive-relay.darkvolg.workers.dev), а Worker уже форвардит его в api.telegram.org. Cloudflare провайдеры не блокируют — они нужны для половины интернета.

⚙️ Настройка с нуля (5 шагов)

Создать бота через @BotFather

В Telegram найди @BotFather, напиши /newbot, придумай:

  • Display name — имя видимое в чате (например, «Улей 5 — мой»)
  • Username — должен заканчиваться на _bot (например, my_hive5_bot)

BotFather пришлёт Token — длинная строка вида 1234567890:AAFxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx. Скопируй её.

Узнать свой Chat ID через @userinfobot

Найди в Telegram @userinfobot, напиши ему любое сообщение. Он пришлёт твой Chat ID — число (для личных чатов положительное, для групп — со знаком минус, например -1001234567890).

Открыть бота из шага 1 и нажать «Start»

❌ Это обязательно! Иначе бот не сможет тебе писать — Telegram блокирует первое сообщение от бота к пользователю который не нажал /start.

Открой своего бота (через ссылку BotFather или поиском по username), нажми /start или кнопку «Запустить».

Зайти на сайт весов → раздел «Telegram»

Подключись к Wi-Fi BeehiveScale, открой http://192.168.4.1, перейди в раздел «📱 Telegram». Вставь:

  • Token — из шага 1
  • Chat ID — из шага 2

Нажми «💾 Сохранить» — настройки запишутся в EEPROM ESP32.

Проверить — кнопка «Тестовое сообщение»

На том же сайте нажми кнопку «📨 Тестовое сообщение». Через 2–3 секунды в Telegram должно прийти приветствие от твоего бота.

Если пришло — всё работает. Дальше отчёты будут приходить по расписанию (см. раздел «Расписание» на сайте).

⚠️ Если не пришло — смотри раздел «Что может пойти не так» ниже на этой странице.

📨 Что приходит в отчёте

Отчёт шлётся в Telegram каждый раз когда срабатывает расписание (например, в 09:00 и 21:00). Пример сообщения:

📊 Отчёт: улей
🕐 Время: 09.05.2026 21:00:10
⚖️ Вес: 4.42 кг
🎯 Эталон: 4.08 кг (зафикс. 05.05, 4 дн назад)
🎯 От зафикс. точки: +0.34 кг
📈 С прошлого замера: +0.02 кг
🌡 Температура: 27.5 °C
🔋 Батарея: 3.85 В (78 %)

Поля отчёта

ПолеИсточник
⚖️ ВесТекущий замер с HX711 (после EMA + dead-band)
🎯 Эталон (+ дата)prevWeight + prevWeightDate (дата фиксации) из EEPROM
🎯 От зафикс. точкиТекущий вес − эталон. Δ за весь сезон / неделю
📈 С прошлого замераТекущий вес − lastReportWeight (вес последнего TG-отчёта). Δ за день/часы
🌡 ТемператураDS18B20 в улье (если датчик подключён). Иначе DS3231
🔋 БатареяADC GPIO34 → пересчёт через делитель 2:1
💡 HTML-форматирование: отчёт использует parse_mode: "HTML" — теги <b> отображаются жирным шрифтом. Если приходят теги в виде текста — обнови прошивку до v5.0.1+.

⏰ Привязка отчётов к расписанию

В v4.1 отчёты слались по интервалу (например, каждые 6 часов). В v5 отчёт привязан к расписанию — конкретное время суток.

📅 Как это работает: на сайте «Расписание» ты задаёшь время (например, 09:00 + 21:00). ESP32 пишет alarm в DS3231, уходит в deep sleep, просыпается ровно в это время → делает замер → шлёт отчёт через CF Worker → возвращается в сон. Расход батареи минимальный.

Сценарии расписания

СценарийВремя в расписанииЦель
Минимальный21:001 отчёт в день — итог за сутки. Батарея живёт максимально долго (~40 дней)
Стандартный09:00 + 21:00Утром «что осталось», вечером «что прибавили». ~30 дней автономии
Подробный06:00 + 12:00 + 18:00 + 22:004 отчёта в день. Видно динамику взятка по часам. ~20 дней
Отладкакаждый часПроверка работы прошивки. Жрёт батарею за неделю
⚠️ Если время в DS3231 неправильное — расписание не сработает. Сначала синхронизируй: сайт → «Настройки → Часы → Sync NTP» (нужен интернет, режим STA). Без интернета — установи время вручную через сайт или Serial-команду SETTIME.

🛠️ Cloudflare Worker (для разработчика)

Если хочешь развернуть свой собственный CF Worker (например, со своим секретом) — исходник в репозитории: cloudflare-worker/src/index.js. Деплой через wrangler deploy.

☁️ Лимит CF Workers (бесплатный план): 100 000 запросов в день. Для пасеки на 100 ульев с отчётами каждый час: 100 × 24 = 2400 запросов в день. Запас в ~40 раз.

❌ Что может пойти не так

«Тестовое сообщение» не приходит

СимптомПричинаРешение
Ошибка 401 Unauthorized Неправильный Token бота Перепроверь Token. Без пробелов, без кавычек. Можно перевыдать через @BotFather → /token
Ошибка 400 Bad Request или chat not found Неправильный Chat ID или ты не нажал /start в боте Перепроверь Chat ID через @userinfobot. Открой бота и нажми /start
CONNECTION_REFUSED / CONNECTION_LOST Нет интернета или Wi-Fi не подключился к роутеру Проверь Экран 6 LCD: должно быть W:OK. Перевключи STA-режим. Проверь что роутер раздаёт интернет
Ошибка от Worker X-Beehive-Secret invalid В прошивке зашит неверный секрет Сверь TG_RELAY_SECRET в Connectivity.h с тем что в CF Worker. Перепрошей
Сообщение пришло, но <b> видны как текст Старая прошивка без parse_mode: HTML Обнови прошивку до v5.0.1+ (в v5.0.21 это уже работает)
Тест работает, но по расписанию ничего не приходит Расписание не настроено или RTC ERROR Сайт → Расписание (поставь время). Проверь Экран 5 (время) и Экран 6 (счётчик пробуждений N)

Telegram приходит, но в неправильное время

Время DS3231 не синхронизировано с реальным. Зайди на сайт → «Настройки → Часы → Sync NTP». Это работает только в режиме STA с интернетом. Без интернета — установи вручную.

🔒 Безопасность Telegram-данных

  • Token бота хранится в EEPROM ESP32 в открытом виде. Доступен только при физическом доступе к плате через USB-консоль или dump прошивки
  • Worker не логирует tokens и chat_id (только метрики количества запросов)
  • Между ESP32 ↔ Worker и Worker ↔ Telegram — HTTPS (TLS). Прослушать в локальной сети нельзя
  • Если Token утёк — перевыдать в BotFather: /token → выбрать бота → новый токен. Старый сразу инвалидируется
ℹ️ Можно ли использовать одного бота на нескольких ульях? Да. Создай группу в Telegram, добавь бота, узнай chat_id группы (через @userinfobot — пересланное из группы). Поставь этот chat_id во всех ульях. Все отчёты будут падать в одну группу — удобно для пасеки на N ульев.
