📌 Pin defines (Pins.h)

Распиновка ESP32-WROOM-32 для v5.0.18:

// HX711 (тензодатчик) #define DT_PIN 16 // GPIO16 (D16) — данные #define SCK_PIN 17 // GPIO17 (D17) — тактирование // I²C шина (LCD + DS3231) #define SDA_PIN 21 // GPIO21 (D21) #define SCL_PIN 22 // GPIO22 (D22) // DS3231 alarm wake (RTC GPIO) — задел на P3, в v5.0.18 не задействован #define SQW_PIN 33 // GPIO33 (D33) — пин подведён, прошивка пока не использует // DS18B20 1-Wire #define TEMP_PIN 4 // GPIO4 (D4) + 4.7kΩ pullup → 3V3 // Кнопки #define BTN_MAIN_PIN 27 // GPIO27 (D27, RTC GPIO ⚡) — тара/калибровка #define BTN_MENU_PIN 26 // GPIO26 (D26) — навигация/OK // ADC батареи #define BAT_ADC_PIN 34 // GPIO34 (D34, ADC1_CH6) — input only! // I²C адреса #define LCD_ADDR 0x27 // LCD 1602 (или 0x3F на некоторых модулях) #define RTC_ADDR 0x68 // DS3231 (фиксированный)
⚠️ Не использовать GPIO 6–11 — это внутренняя SPI flash ESP32. Плата перестанет загружаться. Также избегать 0/2/12/15 (strapping) и 1/3 (USB-Serial).

⏱️ Тайминги и фильтры (Settings.h)

// Чтение HX711 #define SCALE_READ_INTERVAL_MS 600 // Период замера (было 1500 на ESP8266) #define EMA_ALPHA_DEFAULT 0.3f // Дефолт сглаживания (было 0.2) #define SPIKE_FILTER_KG 5.0f // Резкие выбросы > 5 кг отбрасываются #define DEAD_BAND_KG 0.005f // Зона нечувствительности возле 0 // Авто-сон #define AUTO_SLEEP_MS 180000UL // 180 сек = 3 мин (настраивается через сайт) #define SLEEP_GUARD_SEC 60 // Не уходим в сон если до alarm < 60 сек #define KEEPALIVE_BONUS_MS 600000UL // «☕ +10 мин» добавляет 10 минут // LCD #define LCD_REFRESH_MS 200 // Перерисовка экрана (с dirty-check, без мерцания) #define I2C_FREQ_HZ 400000 // 400 kHz fast mode (было 100 kHz) // Кнопки #define BTN_DEBOUNCE_MS 50 #define BTN_MEDIUM_MS 3000 // MAIN MEDIUM = тара #define BTN_LONG_MS 6000 // MAIN LONG = калибровка #define BTN_MENU_HOLD_MS 2500 // MENU удержание = OK
💡 EMA альфа: 0.05–0.2 — сильное сглаживание, плавно но запаздывает. 0.3 (дефолт) — баланс. 0.5–0.9 — быстрая реакция, шумно.

📶 Wi-Fi настройки (Connectivity.h)

Дефолтные значения AP-режима (ESP32 создаёт свою сеть)

// Дефолтная точка доступа (можно сменить через сайт) #define AP_SSID_DEFAULT "BeehiveScale" #define AP_PASS_DEFAULT "12345678" // мин. 8 символов #define AP_CHANNEL 1 #define AP_MAX_CLIENTS 4 // IP по умолчанию: 192.168.4.1 (стандарт ESP32 AP)

Логин/пароль веб-панели

#define WEB_USER_DEFAULT "admin" #define WEB_PASS_DEFAULT "beehive" // сменить после первого входа! #define OTA_PASS_DEFAULT "beehive" // для будущего OTA (если включить)

STA-режим (подключение к домашнему роутеру)

Включается через сайт «Wi-Fi» — не редактируется в коде. Хранится в EEPROM.

ℹ️ Какой режим выбрать?
  • AP режим (дефолт): улей далеко от дома. Подключаешься телефоном к сети BeehiveScale.
  • STA режим: улей в зоне домашнего Wi-Fi. Сайт открывается с любого устройства в сети + работает синхронизация NTP и Telegram-отчёты.

📱 Telegram через Cloudflare Worker

В v5 прямой запрос на api.telegram.org заменён на релай через Cloudflare Worker (обходит блокировку Beeline и др.). Подробности — на странице «Telegram».

// URL релая (фиксированный, не меняется) #define TG_RELAY_URL "https://beehive-relay.darkvolg.workers.dev/sendMessage" // Общий секрет (заголовок X-Beehive-Secret) — должен совпадать с CF Worker #define TG_RELAY_SECRET "<см. в исходнике, не публикуется>" // Token и chat_id хранятся в EEPROM, вводятся через сайт «Telegram»
💡 Token и Chat ID вводятся через сайт 192.168.4.1 → раздел «Telegram». В прошивку не зашиваются.

🕐 NTP (синхронизация часов)

// Часовой пояс: Москва = +3 #define NTP_TZ_OFFSET_SEC 10800 // 3 * 3600 #define NTP_DST_OFFSET_SEC 0 // в РФ нет летнего времени #define NTP_SERVER_1 "pool.ntp.org" #define NTP_SERVER_2 "time.google.com"
💡 Sync time: сайт → «Настройки» → кнопка «Sync NTP». Работает только в режиме STA (нужен интернет). Время записывается в DS3231.

💾 Arduino IDE — настройки платы

Установить core ESP32

Файл → Настройки → Дополнительные URL менеджера плат:

https://espressif.github.io/arduino-esp32/package_esp32_index.json

Затем: Инструменты → Плата → Менеджер плат → найти «esp32» → Установить (версия 2.0.x или 3.0.x).

Выбрать плату DOIT ESP32 DEVKIT V1

Инструменты → Плата → ESP32 Arduino → DOIT ESP32 DEVKIT V1

  • CPU Frequency: 240 MHz
  • Partition Scheme: Huge APP (3MB No OTA / 1MB SPIFFS) ← обязательно!
  • Flash Size: 4MB
  • Upload Speed: 921600
  • Core Debug Level: None

Загрузить скетч

Файл → Открыть → BeehiveScale/BeehiveScale.ino
Инструменты → Порт → COM-порт ESP32 → нажать «Загрузить» (→).

💡 Авто-прошивка: ESP32 DevKit V1 поддерживает auto-reset через DTR/RTS — никаких кнопок зажимать не надо.
❌ Ошибка «Sketch too big» / «Not enough space»: ты выбрал Default Partition (1.31 МБ под код). Прошивка ~1.4 МБ. Поставь Huge APP (3MB No OTA) и пересобери.

💾 EEPROM-карта v5.0.18

В EEPROM ESP32 (эмулируется через NVS, 512 байт) хранятся постоянные настройки:

АдресБайтЧто хранится
04calibrationFactor (float) — коэф. калибровки HX711
44offset (long) — нулевое смещение тары
84lastSavedWeight (float)
121magic 0xA5
134alertDelta (float) — порог алерта в ТГ
174calibWeight (float) — эталонный вес для калибровки
214emaAlpha (float) — сглаживание
251magic2 0xA6
264prevOffset (long) — для отмены тары
304prevWeight (float) — эталон Δ
40–6324AP_PASS (Wi-Fi пароль)
641magic3 0xA7
3134NEW v5: prevWeightDate (uint32_t Unix ts — дата фиксации эталона)
317–3193NEW v5: autoSleepSec (uint16_t + magic 0xA8)
320–3256NEW v5: lastReportWeight (float + magic 0xA9) — для Δ «с прошлого замера»
327–3304NEW v5: lastTempC (float + magic 0xAA) — fallback для TG
💡 Подсветка — оранжевые строки = новые поля v5.0.x, добавлены при портировании с ESP8266.
