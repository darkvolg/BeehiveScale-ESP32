Список компонентов

Для сборки умных весов на базе ESP32-WROOM-32 DevKit V1 понадобятся:

ESP32-WROOM-32 DevKit V1

DOIT, 38 пинов, USB-C. Wi-Fi + BT, deep sleep, RTC GPIO

Flash: 4MB
SRAM: 520KB
CPU: 240 MHz dual-core

Модуль HX711

24-бит АЦП для тензодатчика. Усиление 128. Питание 3.3 В

Каналы: A (gain 128/64) + B
Скорость: 10/80 Hz
DT → D16, SCK → D17
⚡ Pull-up 10 кΩ SCK→3V3 обязательно для sleep

Тензодатчик

Балочный или платформенный, 50–200 кг

Класс точности: C3
4 провода (E+/E−/A+/A−)
Диапазон 0–200 кг

LCD 1602 I²C

16×2 символов, PCF8574, адрес 0x27, питание 5 В

SDA → D21
SCL → D22
VCC → VIN (5 В)

RTC DS3231

Часы реального времени, точность ±2 ppm. Хранит время для расписания и логов

Адрес I²C: 0x68
Батарейка: CR2032
SQW → D33 (опц., задел на P3)

DS18B20

Цифровой термометр 1-Wire, −55…+125 °C. В гильзе для улья

Точность: ±0.5 °C
DATA → D4
Pull-up 4.7 кОм

Кнопки тактовые

MAIN (D27, RTC GPIO — wake) и MENU (D26)

Тип: NO, 4 контакта
Размер: 6×6 мм
INPUT_PULLUP, без внешних R

AS21 V6.0 + 18650

Всё-в-одном: TP4056 (зарядка), DW01 (защита), Boost 5 В, держатель 18650

microUSB зарядка
5V_OUT 1 А, BAT+ raw
Заменяет 3 модуля

Резисторы

4.7 кОм — pull-up DS18B20
2 × 100 кОм — делитель батареи

Мощность: 0.25 W
Точность: 1–5 %
Угольные / металлоплёночные

DIP-сокет 2×19

Female pin headers — съёмный ESP32 для удобства замены

2 × 19 пинов (38)
Шаг: 2.54 мм
Совместим с DevKit V1

LittleFS (внутренний flash)

Лог замеров пишется во встроенный flash ESP32. SD-карта не нужна

~1 МБ под лог
Без окисления контактов
CSV через /api/log

Cloudflare Worker (relay)

Не плата, а внешний сервис. Прокси для Telegram API — обходит блокировку Beeline и др.

Бесплатный план
100k запросов/день
beehive-relay.darkvolg.workers.dev

HT7333 (опционально)

Замена штатного AMS1117 → ток в deep sleep ~7 → ~3 мА. Корпус SOT-89

Iq ≈ 4 мкА
Vout: 3.3 В (фикс.)
Imax: 250 мА

Провода + корпус

Дюпон / гибкий многожильный. ABS-корпус IP54 для улья

AWG 22–26
Длина 10–30 см
Гермоввод PG-7 для DS18B20
💡 Совет: компоненты есть на AliExpress, Ozon, в Чип и Дип, Амперке. Готовые наборы для ESP32 + HX711 + LCD + DS3231 продаются за ~1500 ₽ — это проще чем покупать по отдельности.
💾 Что больше не нужно (по сравнению с ESP8266 v4.1):
  • SD-карта + holder — заменена внутренней LittleFS. Меньше деталей, нет окисления контактов
  • Отдельные TP4056 + DW01 + Boost — заменены модулем AS21 V6.0 «всё-в-одном»
  • Holder 18650 отдельно — встроен в AS21

📋 Краткая таблица подключений к ESP32

Полная распиновка и схема — на странице «Подключение». Здесь — короткая справка:

Компонент Пин ESP32 Назначение Примечание
HX711 DT D16 / GPIO16 Данные АЦП DT_PIN = 16
HX711 SCK D17 / GPIO17 Тактирование SCK_PIN = 17. ⚡ Pull-up 10 кΩ → 3V3 (обязательно для deep sleep, экономит 4 мА)
HX711 VCC 3V3 Питание 3.3 В Стабильнее, чем 5 В
LCD SDA D21 / GPIO21 I²C данные Общая шина с DS3231
LCD SCL D22 / GPIO22 I²C тактирование Общая шина с DS3231
LCD VCC VIN (5 В) Питание подсветки 5 В от AS21, не 3V3!
DS3231 SDA D21 / GPIO21 I²C данные Параллельно LCD
DS3231 SCL D22 / GPIO22 I²C тактирование Параллельно LCD
DS3231 SQW опц. D33 / GPIO33 Alarm wake (задел на P3) RTC GPIO ⚡ — в v5.0.20 не задействован, паяем для будущего
DS18B20 DATA D4 / GPIO4 1-Wire + резистор 4.7 кОм к 3V3
Кнопка MAIN D27 / GPIO27 Тара / калибровка RTC GPIO ⚡, INPUT_PULLUP
Кнопка MENU D26 / GPIO26 Навигация / OK INPUT_PULLUP
Делитель батареи D34 / GPIO34 ADC1_CH6 Input only! Через 2 × 100 кОм
⚠️ Запрещённые пины ESP32:
  • GPIO 6–11 — внутренняя SPI flash, плата перестанет загружаться
  • GPIO 0, 2, 12, 15 — strapping pins, влияют на boot
  • GPIO 1 (TX0), 3 (RX0) — UART0 для USB-Serial
  • GPIO 34, 35, 36, 39 — input only, нельзя как OUTPUT

🔋 Модуль AS21 V6.0 — что внутри

AS21 V6.0 — это «всё-в-одном» модуль питания. Заменяет связку TP4056 + DW01 + Boost 5V + holder 18650:

Блок AS21 Что делает Эквивалент v4.1
TP4056 Контроллер заряда Li-Ion от microUSB (5 В), ток ~1 А TP4056 модуль
DW01 + FET Защита от переразряда (<2.7 В), перезаряда (>4.25 В), КЗ BMS-плата
Boost 5 В Повышает 3.0–4.2 В до стабильных 5 В для ESP32 VIN и LCD MT3608 / похожий
Holder 18650 Встроенный держатель банки, контакты на пружинах Отдельный holder

Подключение AS21 → ESP32

Выход AS21 → Куда Описание
5V_OUT ESP32 VIN Питает ESP32 + LCD (через VIN)
GND ESP32 GND Общая земля
BAT+ (raw) Делитель R1+R2 → D34 Прямое напряжение банки 3.0–4.2 В для ADC
microUSB Зарядное 5 В Только для зарядки 18650 (не прошивка!)
💡 Два USB на устройстве: microUSB на AS21 = зарядка батареи. USB-C на ESP32 DevKit = прошивка / Serial-консоль. Можно подключать оба одновременно.
