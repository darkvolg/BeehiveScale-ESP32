🚀 Как зайти на сайт

В режиме AP (по умолчанию) ESP32 поднимает свою Wi-Fi сеть. Подключайся с телефона/ноутбука и открывай браузер:

ПараметрЗначение
Wi-Fi сеть (SSID)BeehiveScale
Пароль Wi-Fi12345678
IP адрес панелиhttp://192.168.4.1
Логин админкиadmin
Пароль админкиbeehive
⚠️ Сразу смени пароль! После первого входа открой раздел «Wi-Fi → Пароли и доступ» и поставь свой пароль для admin (и желательно сменить пароль AP на не-дефолтный).
💡 Режим STA (домашний роутер): в разделе «Wi-Fi» можно переключить ESP32 на подключение к домашнему роутеру. Тогда сайт открывается с любого устройства в твоей сети по IP-адресу из роутера. Удобно когда улей рядом с домом — не нужно каждый раз переключать Wi-Fi.

Графики с тач-курсором

Палец/мышь по графику веса — в реальном времени видишь значение в точке. Работает на тачскрине телефона.

📍

Зафиксировать с датой

Кнопка «📍 Зафиксировать» сохраняет эталон + дату фиксации. Дельта показывается в формате «От зафикс. точки (3 дн назад)».

☕

Продлить +10 мин

Отодвигает auto-sleep на 10 минут — пока ты сидишь и смотришь графики ESP32 не уснёт.

📱

Мобильная вёрстка

Респонсив дизайн — нормально читается на телефоне. Большие кнопки для пальца.

⏰

Расписание

Время автоматических замеров и Telegram-отчётов настраивается прямо с сайта (например 09:00 + 21:00).

⚖️

Калибровка через сайт

Поставь любую гирю, введи её точный вес, нажми «Сохранить» — без танцев с кнопками.

💾

Backup настроек

Скачать/восстановить все настройки в JSON. Удобно при замене ESP32 или массовой настройке нескольких ульев.

🚀

Быстрая загрузка

HTML отдаётся чанками по 4 КБ + кеш статистики SD. Страница открывается мгновенно.

📲 PWA — установка на главный экран

С v5.0.16 сайт поддерживает Progressive Web App. На сайте есть /manifest.json, /sw.js (service-worker), /icon.svg (SVG-иконка пчелы), apple-mobile-web-app-* meta-теги.

Что даёт PWA

  • Иконка пчелы на главном экране телефона — один тап → весы
  • Полноэкранный режим без адресной строки
  • Offline-страница работает даже если ESP32 недоступна (последние данные из кеша)
  • Theme-color #f5a623 (медовый) в системных панелях

📅 Вкладка Архив (v5.0.16+)

История замеров за период с пресетами и аномалиями. Главная фишка v5.0.21 — пресет «↩ С прошлого визита»: автоматически выбирает диапазон с момента твоего последнего открытия сайта.

Пресеты

  • Сегодня · 3 дня · Неделя · Месяц · Всё — скользящие окна
  • ↩ С прошлого визита 🆕 v5.0.21 — авто от /api/last-visit timestamp (EEPROM addr 331-336)
  • Date-range — произвольный диапазон через два календарика

Что в архиве

  • Сводка периода: Δ веса, кол-во записей, разбивка по дням
  • Лента дней — карточка на день с месячными группировками
  • 🔴 Маркер аномалии — если падение веса > alert_delta
  • Скачать CSV за период (стриминг)

🔌 REST API эндпоинты

Сайт использует JSON API — можно дёргать из своих скриптов / Home Assistant.

📊 Данные и управление весами

GET/api/data

JSON с текущими данными: вес, температура, батарея, время, статус Wi-Fi, keepLeftSec (до auto-sleep) и т.д.

POST/api/tare

Тарировать весы (обнулить).

POST/api/save

«📍 Зафиксировать» — сохранить текущий вес как эталон + дату.

POST/api/keepalive

«☕ Продлить +10 мин» — отодвигает auto-sleep.

POST/api/settings

Применить настройки: emaAlpha, alertDelta, calibWeight, autoSleepSec.

POST/api/calib/set

🆕 Точная калибровка через сайт. Параметры: knownWeightKg.

POST/api/ntp

Синхронизировать DS3231 с NTP (нужен режим STA + интернет).

POST/api/reboot

Перезагрузка ESP32.

📜 Лог замеров (LittleFS)

GET/api/log

Скачать CSV-лог из LittleFS. Поля: datetime,weight_kg,temp_c,bat_v,bat_pct.

GET/api/log/json

🆕 JSON-лог для графика (с throttle 30 сек на сервере, чтобы не нагружать).

POST/api/log/clear

Очистить лог.

GET/api/daystat

🆕 Дневная статистика (мин/макс/среднее веса).

GET/api/period?from=YYYY-MM-DD&to=YYYY-MM-DD

🆕 v5.0.16 JSON-стрим записей за произвольный период. Используется вкладкой 📅 Архив. Поля: datetime, weight_kg, temp_c, bat_v, bat_pct.

GET/api/log?from=YYYY-MM-DD&to=YYYY-MM-DD

🆕 v5.0.16 CSV за диапазон дат (стриминг). Старый формат ?date=YYYY-MM-DD совместим.

GET/api/last-visit

🆕 v5.0.21 Timestamp прошлого открытия сайта (Unix). Для пресета «↩ С прошлого визита» в Архиве. Первый вызов за boot возвращает старое значение из EEPROM и обновляет на «сейчас» (если прошло >1 часа). Последующие в той же сессии — кешированное значение.

GET/archive

🆕 v5.0.16 Alias на главный SPA. Удобно для прямой ссылки на вкладку Архив (закладки браузера).

GET/manifest.json

🆕 v5.0.16 PWA-манифест: name, short_name, icons, theme_color #f5a623, display standalone.

GET/sw.js

🆕 v5.0.16 Service-worker для PWA. Кеширует HTML и иконку для offline-доступа. API-запросы всегда идут в сеть.

GET/icon.svg

🆕 v5.0.16 SVG-иконка пчелы с ульем для PWA. Масштабируется без потерь.

GET/chart

🆕 Полноэкранная страница графика с тач-курсором.

📱 Telegram

POST/api/tg/settings

🆕 Сохранить Telegram token + chat_id.

POST/api/tg/test

🆕 Отправить тестовое сообщение через CF Worker.

📶 Wi-Fi и доступ

POST/api/wifi/settings

🆕 Сменить режим (AP/STA), SSID/пароль домашнего роутера, пароль AP.

POST/api/auth/password

🆕 Сменить пароль admin для входа в веб-панель.

POST/api/auth/ota

🆕 Сменить пароль OTA (для будущей прошивки по воздуху).

💾 Backup

GET/api/backup

🆕 Скачать backup всех настроек (JSON): EEPROM, Wi-Fi, Telegram, расписание.

POST/api/backup/restore

🆕 Восстановить настройки из ранее скачанного backup.

{ "weight": 4.42, // кг (после EMA + dead-band) "prevWeight": 4.08, // зафиксированный эталон "prevWeightDate": "2026-05-05 23:04", // дата фиксации эталона "lastReportWeight": 4.40, // вес последнего TG-отчёта "tempC": 27.5, // улей (DS18B20) "rtcTempC": 28.0, // воздух (RTC DS3231) "batV": 3.85, // напряжение батареи "batPct": 78, // % заряда (3.0 В = 0%, 4.2 В = 100%) "datetime": "2026-05-09 14:30:22", // время DS3231 "wifiOk": true, // подключён к роутеру (STA) или AP активен "keepLeftSec": 540, // секунд до auto-sleep "uptimeSec": 1234, // время работы с последнего пробуждения "wakeCount": 42, // счётчик пробуждений (Экран 6) "calibrationFactor": 432167.0, // коэффициент калибровки HX711 "fwVersion": "5.0.15" }
💡 Интеграция в Home Assistant: можно сделать REST sensor с URL http://192.168.4.X/api/data — и все поля доступны как entities в HA. Подходит для дашбордов и автоматизаций.

📊 График веса с тач-курсором

На странице «График» (или /chart для полноэкранного режима) — интерактивная кривая веса по времени:

  • Палец / мышь по графику → курсор показывает значение в точке (вес и время)
  • Зелёная линия = вес. Оранжевая = температура улья (DS18B20)
  • Точки фиксации эталона отмечены вертикальной линией
  • Период: 1 день / 7 дней / 30 дней — переключатель сверху
  • Данные подгружаются с throttle 30 сек чтобы не грузить ESP32
💡 Полноэкранный график на телефоне: открой http://192.168.4.1/chart — это отдельная страница без меню, занимает весь экран. Удобно смотреть на телефоне в портретном режиме.

🔄 Wi-Fi: AP vs STA

Режим AP (по умолчанию)

  • ESP32 создаёт свою Wi-Fi сеть BeehiveScale / 12345678
  • IP всегда 192.168.4.1
  • Подходит когда улей далеко от дома (нет роутера)
  • Минусы: нет интернета → нет NTP-синка и нет Telegram-отчётов (Telegram нужен только когда подключаешься телефоном к ESP32 и сам активируешь?)

Режим STA (подключение к роутеру)

  • ESP32 коннектится к домашнему Wi-Fi (SSID + пароль вводишь на сайте)
  • IP назначает роутер (DHCP). Смотри в роутере → клиенты → BeehiveScale
  • Подходит когда улей рядом с домом
  • Плюсы: работает Telegram, NTP, доступ из любой точки сети
ℹ️ Переключение в STA: сайт → «Wi-Fi» → выбрать STA → ввести SSID + пароль роутера → Сохранить. ESP32 перезагрузится, попробует подключиться. Если не получилось за 10 сек — возвращается в AP.
⚠️ Сброс Wi-Fi: зажми MENU 5 сек на главном экране — настройки Wi-Fi сбросятся на дефолт (AP / BeehiveScale / 12345678). Помогает если забыл пароль или ESP32 не подключается к новому роутеру.

🛡️ Безопасность

  • HTTP Basic Auth на всех /api/* и страницах настроек (admin / beehive по умолчанию)
  • HTTPS не поддерживается — ESP32 не тянет TLS-сервер с приличной скоростью. Это нормально для локальной сети
  • Telegram-token хранится в EEPROM в открытом виде — но EEPROM недоступен снаружи (только через USB-консоль с физическим доступом)
  • В CF Worker есть проверка X-Beehive-Secret — посторонний не сможет дёргать релай от твоего имени
⚠️ Если выставляешь весы в STA-режим в публичную сеть (например офисный Wi-Fi гостевой) — обязательно смени пароли admin и AP на не-дефолтные. Иначе любой в той же сети сможет открыть твою панель.
