🔘 Управление кнопками (важно изменилось в v5!)

⚠️ Режимы кнопок переделаны: на ESP8266 v4.1 тара была «4 коротких нажатия MAIN». В v5 для защиты от случайных нажатий — 3-секундное удержание MAIN + подтверждение через MENU=OK. Если ты привык к старой схеме — отвыкай.

Кнопка MAIN D27 / GPIO27 (RTC GPIO ⚡)

Действие Длительность Результат
Короткое нажатие < 1 сек Ничего (защита от случайного тарирования). Только зажигает LCD после wake.
MEDIUM ~3 сек ТАРА — открывает диалог «Выполнить тару? MENU=OK». Если в течение 5 сек не нажать MENU — отмена.
LONG ~6 сек КАЛИБРОВКА — мастер калибровки по эталонной гире (см. ниже).
В режиме CF (Экран 7) короткое Сменить шаг подстройки: 10 → 1 → 0.1 → 10 ...
В режиме CF (Экран 7) длинное Сохранить CF в EEPROM и выйти

Кнопка MENU D26 / GPIO26

Действие Длительность Результат
Короткое нажатие < 1 сек Переключение между 8 экранами LCD по кругу.
Удержание ~2.5 сек OK — подтверждение в диалогах (после MAIN MEDIUM = тара). Из меню — возврат на Экран 1.
В режиме CF (Экран 7) короткое CF + шаг (увеличить)
В режиме CF (Экран 7) длинное CF − шаг (уменьшить)
Удержание 5 сек на Экране 1 ~5 сек Сброс Wi-Fi настроек на дефолт (AP-режим, BeehiveScale / 12345678)
💡 Wake-press guard: сразу после пробуждения из deep sleep первое нажатие MAIN не открывает тару — оно только зажигает LCD. Это защита от случайного тарирования при выходе из сна.

📟 Экраны LCD (8 штук, переключение кнопкой MENU)

В v5 добавлен Экран 8 — Диагностика (самотест железа). Остальные 7 экранов аналогичны v4.1, но содержимое чуть изменено.

Экран 1 — Вес и время
Ves: 4.42*kg
21:35:22 W
* = показания стабильны (для авто-фиксации). W = Wi-Fi OK.
Экран 2 — Дельта (Δ)
D:+0.34kg
Pred:4.08kg
D = текущий − зафиксированный эталон (prevWeight). Pred = эталон. Меняется кнопкой «📍 Зафиксировать» на сайте.
Экран 3 — Батарея
Bat:3.85V 78%
Li-Ion 1S
При <10% — мигает «!LOW BATTERY!»
Экран 4 — Температура
T:27.5C R:28.0C
H: -- (DS18)
T = улей (DS18B20), R = воздух (RTC DS3231). Влажность не измеряется.
Экран 5 — Дата и время
09.05.26 14:30
RTC OK
«RTC ERROR!» = села CR2032, замени батарейку и синхронизируй NTP.
Экран 6 — Статус
CF:432167
W:OK N:42
CF = калибровочный коэффициент. N = пробуждений из сна (растёт при срабатывании расписания).
Экран 7 — Меню калибровки
CF:432167.0
MAIN=Vojti
MAIN = вход в режим ручной подстройки CF. Для опытных.
Экран 8 — Диагностика 🆕 v5
Diagnostika...
HX711... OK
Проходит самотест: HX711 / DS18B20 / RTC / Battery. Каждый компонент → OK или FAIL. MAIN = повторить тест.
💡 LCD без мерцания: в v5 добавлен dirty-check кеш (рисуется только то, что изменилось) + I²C 400 kHz fast mode. Цифры веса больше не мигают при пересчёте.

📊 Двойная дельта веса (новое в v5)

В v5 теперь две точки отсчёта дельты — гибкость для пасечника:

Где видно Что считается Как сбросить
📈 «С прошлого замера» Δ от lastReportWeight Авто после каждого Telegram-отчёта
🎯 «От зафиксированной точки» Δ от prevWeight + дата фиксации Только вручную: сайт → кнопка «📍 Зафиксировать»
💡 Пример сценария: поставил улей → нажал «📍 Зафиксировать» → началась запись эталона. Через неделю «От зафиксированной точки» покажет точный прирост мёда (например +3.2 кг с 02.05). Параллельно «С прошлого замера» показывает дневное изменение (например +0.34 кг с утра) для оперативного контроля.
💡 Эталон переживает reset — prevWeight + дата фиксации хранятся в EEPROM (адреса 30 + 313, magic 0xA9). Не теряется при перезагрузке/прошивке.

⚖️ Калибровка через кнопки (MAIN 6 сек)

Делается один раз при сборке весов и потом раз в сезон. Понадобится гиря известного веса: 1 кг (5-литровая бутылка воды), лучше 5–10 кг под рабочий диапазон.

Снять нагрузку с платформы

Платформа должна быть пустой и горизонтальной.

Запустить калибровку: зажать MAIN

Через 3 сек на LCD: «Otpust = TARA!» — НЕ отпускай. Через 6 сек сменится на «Otpust = KALIBR» — теперь отпускай.

Ubrat gruz!
Zhmi knopku...

Нажать MENU — тара пустых весов

Postav gruz
Zhmi knopku...

Положить эталонный груз

Поставь гирю на платформу, подожди 2–3 сек чтобы показания устаканились.

Нажать MENU — сохранить

OK! Factor:
432167

Калибровочный коэффициент сохраняется в EEPROM навсегда.

💡 Удобнее через сайт: зайди на 192.168.4.1 → вкладка «Калибровка». Поставь гирю, в поле введи её точный вес (например, 5.0) и нажми «Сохранить» — без танцев с кнопками. Можно с любым весом.
⚠️ Не калибруй в улье: пчёлы летают, машут крыльями — это вибрация, портит точность. Калибровать в гараже на ровной поверхности.

💤 Авто-сон (Deep Sleep)

После 3 минут бездействия (никто не нажимает кнопки и не открывает сайт) — автоматический переход в глубокий сон. Это даёт автономию 30–40 дней на одной зарядке 18650.

Sleep guard 60 сек

Если до следующего срабатывания расписания меньше 60 сек, ESP32 не уходит в сон (избегаем цикла «проснулся-уснул»).

Запись лога и отключение питания периферии

Лог пишется в LittleFS. lastReportWeight, lastTempC, эталон сохраняются в EEPROM. Wi-Fi и LCD отключаются. HX711 → power_down (1.5 мА → 1 мкА).

Пробуждение — несколько способов

  • По таймеру ESP32 (расписание) → новый замер + Telegram-отчёт. Это основной способ в v5.0.18
  • По кнопке MAIN (D27 — RTC GPIO) — ручное пробуждение
  • Кнопкой RST на плате (полная перезагрузка, теряется RTC RAM)
  • По alarm DS3231 (D33 — RTC GPIO) — опц., задел на P3. Сейчас не задействовано в коде, провод для будущего

Кнопка ☕ Продлить +10 мин (на сайте)

На главной странице сайта есть кнопка «Продлить +10 мин» — отодвигает auto-sleep если ты сидишь и смотришь графики. В /api/data приходит поле keepLeftSec с обратным отсчётом до сна.

💡 Настройка авто-сна: через сайт «Настройки → Авто-сон» — диапазон 0…600 сек. По умолчанию 180 сек (3 мин). 0 = не засыпать (отладка).

⏰ Расписание замеров (новое в v5)

ESP32 умеет просыпаться по расписанию, делать замер, слать отчёт в Telegram и снова уходить в сон. Подробности — на странице «Веб-интерфейс».

Зайти на сайт → раздел «Расписание»

Подключись к Wi-Fi BeehiveScale, открой 192.168.4.1, выбери «Расписание».

Выбрать время замера

Например, 09:00 (утренний) и 21:00 (вечерний). Можно одно время, можно несколько.

ESP32 рассчитает alarm и уйдёт в сон

DS3231 пробудит ESP32 ровно в назначенное время. Замер → Telegram-отчёт → снова в сон.

Проверить

На Экране 6 счётчик пробуждений N будет расти после каждого срабатывания. В логе сайта появится новая строка.

⚠️ Если время в DS3231 неправильное — расписание не сработает. Сначала синхронизируй через сайт: «Настройки → Часы → Sync NTP» (нужен интернет, режим STA).

🔋 Энергопотребление

СостояниеТокДлительность за день
Active + Wi-Fi (отчёт TG) 80–90 мА ~30 сек × 2 раза = 1 мин/день
Active без Wi-Fi (после отчёта) 30–50 мА ~3 мин до auto-sleep × 2 = 6 мин/день
Deep sleep с штатным AMS1117 ~7 мА ~23.5 ч/день — основной потребитель
Deep sleep после замены LDO на HT7333 ~3 мА планируется доводка

Сейчас (с AMS1117) автономия ~12 дней на одной зарядке 18650 (3000 мА·ч × ~70% usable). После замены LDO на HT7333 — 30–40 дней.

💡 Доводка: HT7333 — замена SOT-89 LDO опустит ток в спячке с ~7 до ~3 мА. Корпус совместим с AMS1117, перепайка ~2 минуты.
